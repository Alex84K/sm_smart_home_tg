# Соглашения Go-кода

Только то, чего нет в ADR. Структура пакетов и границы — ADR-0016, ADR-0017, ADR-0018.

## Ошибки

- Оборачивай с контекстом: `fmt.Errorf("coreclient: get photo: %w", err)`. Префикс — пакет и действие.
- Ожидаемые состояния — sentinel-ошибки пакета (`var ErrCoreUnavailable = errors.New(...)`), проверка через `errors.Is/As`, не по тексту.
- `panic`, `log.Fatal`, `os.Exit` — только в `main` и только на старте. Воркер возвращает ошибку или сам перезапускается.
- Ошибку либо возвращай, либо логируй — не оба сразу.

## Логи

- Только `log/slog`, логгер приходит через конструктор или `Deps`.
- Ключи в `snake_case`; ошибка — `slog.Any("err", err)`; идентификаторы — `chat_id`, `user_id`, `client`.
- Без секретов: токены бота, пароли — только через маскировку `platform/log`.
- `Info` — изменения состояния; `Debug` — подробности сообщений; не логируй в горячих циклах на `Info`.

## Context и горутины

- `ctx context.Context` — первый параметр у всего, что ходит в сеть или ждёт.
- У каждой горутины есть владелец и способ остановки через `ctx`; запускай фоновую работу через `run.Runner`.
- Конструкторы не запускают работу и не делают сетевых вызовов — только `Run(ctx)`.

## Время, случайность, внешний мир

- Текущее время — через `Clock` (`Now()`, таймеры), не `time.Now()` в логике для детерминированных тестов.
- Внешние процессы, Telegram — за портами/интерфейсами; в тестах — ручные fakes.

## Тесты

- Табличные тесты, `t.Run` с понятными именами; `-race` всегда.
- Fakes пиши руками рядом с тестом; библиотеки моков не используем.
- Без `time.Sleep` для синхронизации — fake-часы, каналы, `t.Context()`.

## Именование и файлы

- Пакеты — одно короткое слово в нижнем регистре, без `utils`, `common`, `helpers`.
- Файлы: `app.go`, `client.go`, `middleware.go`, `errors.go`.
- Конфигурационные значения — с единицами в имени поля или типом `time.Duration`.

## Комментарии

- Doc-комментарий у каждого экспортируемого идентификатора и у пакета.
- Комментарий объясняет «почему», а не «что». Ссылки — на ADR или capability (`ADR-0017`, `telegram-bot`).

## Коммиты

- Формат: `<область>: <что сделано>` (`telegram: throttle getUpdates conflict warning`, `client: add status check`).
- Один коммит — одно логическое изменение; `make check` зелёный.
